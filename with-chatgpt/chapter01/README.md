# Project 1 | Explore the AI Landscape (Mini Project)

## Problem Statement

**Objective**: Build intuition about where deep learning fits among AI techniques.

Create a table with 15 real-world AI applications (for example, spam detection, handwritten digit recognition, stock price forecasting, medical image analysis, recommendation systems, speech recognition, fraud detection, machine translation, etc.).

For each application, include:

- Problem description
- Input data type (tabular, image, text, audio, time series, etc.)
- Task type (classification, regression, clustering, generation, recommendation, etc.)
- Would you choose Classical Machine Learning, Deep Learning, or either?
- Brief justification (1–2 sentences)

The goal is not to be "correct" in every case, but to begin thinking like an engineer who selects methods based on the nature of the problem.
